# Vehikl-Oil-Change
Setup instructions:
1. Ensure that php and laravel are properly installed
2. Download the repository and extract the project
3. Open a command terminal in the OilChangeChallenge directory
4. Run the command: composer install
5. Run the command: php artisan migrate
6. To launch the server, run the command: php artisan serve
7. Open http://localhost:8000/ in a broser to view the application
